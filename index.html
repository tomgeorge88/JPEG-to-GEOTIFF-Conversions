JPEG to GeoTIFF Overlay Tool

Select a JPEG from the input folder, match it to a lower-resolution reference GeoTIFF, overlay it in the correct spatial location, and export the result as a GeoTIFF.

1. Select Input Folder

No input folder selected
This folder is searched for JPEG or JPG files.

2. Select JPEG File

Select the JPEG file to place into the reference GeoTIFF.

3. Select Reference Folder

No reference folder selected
This folder is searched for TIFF or TIF files.

4. Select Reference GeoTIFF

This file provides the spatial extent and coordinate system for the output.

5. Select Output Folder

No output folder selected
The GeoTIFF output will be written here.
